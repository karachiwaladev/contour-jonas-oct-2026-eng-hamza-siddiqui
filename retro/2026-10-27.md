**Evidence**

- Friction ([git log](https://github.com/karachiwaladev/contour-jonas-oct-2026-eng-hamza-siddiqui/commits/main)): 1,001 of 1,029 commits are "Update prompt log", one per idle tick.
- Human corrections, "stop loop" six times: [PL#2](https://github.com/karachiwaladev/contour-jonas-oct-2026-eng-hamza-siddiqui/blob/868f1e3/.claude/logs/prompts.jsonl#L2), [PL#10](https://github.com/karachiwaladev/contour-jonas-oct-2026-eng-hamza-siddiqui/blob/868f1e3/.claude/logs/prompts.jsonl#L10), [PL#97](https://github.com/karachiwaladev/contour-jonas-oct-2026-eng-hamza-siddiqui/blob/868f1e3/.claude/logs/prompts.jsonl#L97), [PL#118](https://github.com/karachiwaladev/contour-jonas-oct-2026-eng-hamza-siddiqui/blob/868f1e3/.claude/logs/prompts.jsonl#L118), [PL#157](https://github.com/karachiwaladev/contour-jonas-oct-2026-eng-hamza-siddiqui/blob/868f1e3/.claude/logs/prompts.jsonl#L157), [PL#1184](https://github.com/karachiwaladev/contour-jonas-oct-2026-eng-hamza-siddiqui/blob/868f1e3/.claude/logs/prompts.jsonl#L1184).

**E1** (`SKILL.md`, "Running on a schedule"): replace `/loop 1m /factory-loop` with `/loop 10m /factory-loop`, and add one line: "Each tick loads this whole skill, even when idle; don't poll faster than every 10 minutes."

- Audit finding #3 (prompt-audit, medium): `SKILL.md` "Browser verification" steps 1–5 are an older copy of `browser-verifier.md`. They lack the isolated context, the server wait, the port fallback and the old-data reload, so the two instructions have drifted apart.

The screenshot rules (no `fullPage`, retry once then FAIL, check the file exists) go in `browser-verifier.md`, which is the file that runs them.

## C10. Windows tooling trips the loop

**Evidence**
- Failed checks (TR):
  - `gh` was not on PowerShell's `PATH` and was not logged in (2 failures);
  - `/tmp/…` paths passed to `node` don't resolve.
- Failed check (today): `claude -p "/skill-doctor"` from Git Bash arrived as `C:/Program Files/Git/skill-doctor`. Git Bash rewrites a leading `/`, so both audits had to be rerun with `MSYS_NO_PATHCONV=1`.
- Friction (today): headless runs print "Ignoring 3 permissions.allow entries… this workspace has not been trusted".

**E8** (`SKILL.md`, Prerequisites): add "On Windows: if `gh` is missing, reload `PATH` from the Machine and User values. Use the session scratchpad, not `/tmp`. From Git Bash, prefix `claude -p "/…"` with `MSYS_NO_PATHCONV=1`."
